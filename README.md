# Aiman Uddin - Full-Stack Developer Portfolio

[![Live Demo](https://img.shields.io/badge/Live_Demo-View_Here-blue?style=for-the-badge)](https://aiman-uddin.vercel.app/)
[![GitHub](https://img.shields.io/badge/GitHub-Aiman--012-181717?style=for-the-badge&logo=github)](https://github.com/Aiman-012/Aiman-Uddin)

A modern, high-performance personal portfolio showcasing my journey, selected works, and enterprise integrations. Built with React, Vite, and Tailwind CSS v4, featuring fluid animations and a polished user interface.

## ✨ Key Features

- **Ambient Animations:** A continuous glowing background and dynamic rotating text in the hero section.
- **Interactive Custom Cursor:** Smooth spring-physics cursor with a satisfying click-ripple effect.
- **Infinite Tech Marquee:** A seamless, right-to-left scrolling banner showcasing my technical stack.
- **Scroll Progress Indicator:** A minimal progress bar tracking page scroll depth.
- **Dark/Light Theme:** Elegant, high-contrast visual design perfectly adaptable to user system preferences.
- **Project Showcase:** Live modal previews and direct GitHub repository links.

## 🛠️ Tech Stack

- **Framework:** React 18 (Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion (`motion/react`)
- **Routing:** React Router v6
- **Icons:** Lucide React & React Icons

## 🚀 Quick Start

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aiman-012/Aiman-Uddin.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Aiman-Uddin
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
